# Gym workouts

Gym has four sections: Weekly Plan, Build, Library and History.

Users choose exercises from the library, name their workout, enter their own optional targets and save a reusable routine. A routine can be scheduled, started immediately or used to record a completed workout. New exercise fields start with one empty logging row; repetitions, weights, duration, distance and rest targets stay blank until entered by the user.

The library includes exercise and equipment illustrations. Illustrations identify movements and equipment; a qualified trainer should check technique, setup and suitability. Injury, pain, health conditions and specialist needs require appropriate professional advice.

Saved routines, scheduled workouts and actual history use the existing owner-scoped Gym records. Existing metadata remains accepted for backward compatibility. Removing a built-in selection does not delete user-saved routines or historical results.

The mobile library endpoint supplies the same exercise catalogue, with an empty legacy collection for compatibility with existing clients. Workouts are created from the user's selected exercises and targets.

Validation covers catalogue assets, exercise identities, empty logging defaults, saved-routine compatibility and workout completion.
